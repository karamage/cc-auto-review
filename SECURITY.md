# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's vulnerability reporting](https://github.com/karamage/cc-auto-review/security/advisories/new). Do not open a public issue.

## Supported versions

Only the [latest release](https://github.com/karamage/cc-auto-review/releases/latest) receives security fixes. Versions before 0.1.2 do not confine Claude's file access during reviews, so a pull request could use hidden instructions to read or write files on your machine. Please update.

---

## 脆弱性の報告

脆弱性は [GitHub の非公開の報告機能](https://github.com/karamage/cc-auto-review/security/advisories/new)から報告してください。公開の Issue には書かないでください。

## サポートするバージョン

セキュリティの修正を行うのは[最新のリリース](https://github.com/karamage/cc-auto-review/releases/latest)だけです。0.1.2 より前の版は、レビュー中の Claude のファイルアクセスを限定していません。PR に紛れた指示で手元のファイルを読み書きされる恐れがあるので、更新してください。
